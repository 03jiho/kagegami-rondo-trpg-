# 카게가미 론도

다이쇼(大正) 시대 일본을 배경으로 한 코스믹 호러 솔로 TRPG 텍스트 어드벤처입니다. 브라우저에서 바로 실행되며, 별도 설치나 빌드 과정이 없습니다.

## 배경

다이쇼 시대 초입, 도쿄 외곽. 근대화의 신작로가 산기슭까지 뻗어오던 어느 날, 자작 가문 아마미야가에서 일가족 상해 사건이 벌어진다. 가문이 대대로 지켜온 봉인이 공사의 진동으로 금이 가기 시작한 것이다. 봉인 아래 잠든 것은 민담 속 요괴가 아니다 — 별의 저편에서 흘러든, 이름조차 온전히 발음할 수 없는 무언가의 파편이다.

## 실행 방법

바로 플레이: **https://03jiho.github.io/kagegami-rondo-trpg-/**

로컬에서 열려면 `index.html` 파일을 브라우저로 열면 됩니다.

```bash
# 예시 (로컬에서 바로 열기)
start index.html
```

## 놀이법

- **신원 선택**: 퇴마 음양사 / 마인 검객 / 근대 학자 / 무녀 / 헌병 조사관 중 하나를 골라 고유한 능력을 얻는다.
- **능력치 배분**: 술(術) · 지(知) · 담(膽) 세 스탯에 포인트를 배분한다. 술은 파고드는 힘, 지는 스스로의 안전, 담은 유키에와의 인연을 지킨다.
- **핵심 루프**: 응접실 → 서재 → 별채 → 정원 → 지하 기단, 다섯 장을 거치며 조사(안전) / 파고든다(위험 동반, 다음 장으로) / 물러나 결전으로 향한다 중 선택한다.
- **이중 게이지**: 봉인의 균열과 스스로의 침식이 함께 오른다. 침식이 6을 넘으면 위험한 선택지가 열리고, 10에 닿으면 그 자리에서 폭주 엔딩이 확정된다.
- **인연**: 유일한 목격자 유키에와의 신뢰는 위험한 선택으로 망가지고, 담 판정으로 한 번 회복을 시도할 수 있다.
- **엔딩 5종**: 봉인 재건 / 소멸 / 수거 / 은폐 / 폭주 — 최종 균열·침식 수치와 선택에 따라 갈린다.

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음, 파일 하나로 동작)
- 폰트: Google Fonts (Nanum Myeongjo, Noto Serif KR, IBM Plex Mono)
- 지금까지 확인한 결말(5종 중 몇 개)은 `localStorage`에 저장되어 시작 화면에 표시된다
