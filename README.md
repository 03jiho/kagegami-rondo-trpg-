# 카게가미 론도

다이쇼(大正) 시대 일본을 배경으로 한 코스믹 호러 솔로 TRPG 텍스트 어드벤처입니다. 브라우저에서 바로 실행되며, 별도 설치나 빌드 과정이 없습니다.

## 배경

다이쇼 시대 초입, 도쿄 외곽. 근대화의 신작로가 산기슭까지 뻗어오던 어느 날, 자작 가문 아마미야가에서 일가족 상해 사건이 벌어진다. 가문이 대대로 지켜온 봉인이 공사의 진동으로 금이 가기 시작한 것이다. 봉인 아래 잠든 것은 민담 속 요괴가 아니다 — 별의 저편에서 흘러든, 이름조차 온전히 발음할 수 없는 무언가의 파편이다.

## 실행 방법

바로 플레이: **https://03jiho.github.io/kagegami-rondo-trpg-/**

로컬에서 열려면 `index.html` 파일을 브라우저로 열면 됩니다.

```bash
# 예시 (로컬에서 바로 열기)
start index.html
```

## 놀이법

- **제목의 의미**: 아마미야가 사람들은 봉인 아래의 존재를 함부로 '카게가미(影神)'라 부르지 않고 그저 '소신'이라 불러왔다. 하지만 이 봉인은 대를 이어 몇 번이고 금이 가고 다시 메워졌다 — 같은 곡이 처음으로 되돌아가 반복되듯이. 그 되풀이가 '론도'다. 인트로와 5번째 장(봉인의 회랑)에서 이 유래를 직접 확인할 수 있다.
- **신원 선택**: 퇴마 음양사 / 마인 검객 / 근대 학자 / 무녀 / 헌병 조사관 중 하나를 골라 고유한 능력을 얻는다. 각 신원은 능력치 보너스(술·지·담 중 하나 +1)와 1회용 전용 히든 행동(판정 없이 확정 발동)을 함께 갖는다.
- **해석 렌즈**: 같은 조사 대상이라도 신원마다 다르게 읽는다 — 음양사는 술식의 잔향을, 검객은 핏속의 것의 반응을, 학자는 문헌 지식을, 무녀는 할머니와 영혼의 목소리를, 헌병은 은폐된 정황을 짚어낸다. 같은 장을 다른 신원으로 다시 플레이하면 다른 게임처럼 느껴지도록 설계했다.
- **능력치 배분**: 술(術) · 지(知) · 담(膽) 세 스탯에 포인트를 배분한다. 술은 파고드는 힘, 지는 스스로의 안전, 담은 유키에와의 인연을 지킨다. 신원 보너스는 배분과 별개로 더해진다.
- **핵심 루프**: 응접실 → 서재 → 별채 → 정원 → 봉인의 회랑 → 지하 기단, 여섯 장을 거치며 조사(안전) / 파고든다(위험 동반, 다음 장으로) / 물러나 결전으로 향한다 중 선택한다.
- **주사위 판정**: TRPG가 낯선 플레이어를 위해 DC 옆에 대략적인 성공 확률(%)이 함께 표시된다. 선택지마다 성격에 맞는 이모지(🎲 판정, 🛡️/🔍 안전, ✨ 판정 없이 성공하는 히든 등)도 붙는다.
- **이중 게이지**: 봉인의 균열과 스스로의 침식이 함께 오른다. 침식이 6을 넘으면 위험한 선택지가 열리고, 10에 닿으면 그 자리에서 폭주 엔딩이 확정된다.
- **인연**: 유일한 목격자 유키에와의 신뢰는 위험한 선택으로 망가지고, 담 판정으로 한 번 회복을 시도할 수 있다.
- **간토 대지진 복선**: 균열이 깊어질수록 잔진동을 암시하는 기척이 섞여 등장하고, 봉인의 회랑에서는 대대로 이어진 봉인 보수 시점이 큰 지진이 있던 해와 겹친다는 단서를 발견할 수 있다 — 모든 엔딩이 이 복선을 서로 다른 방식으로 회수한다.
- **엔딩 5종**: 최종장에 도착하면 각 선택지가 무엇을 뜻하는지 안내 문구가 먼저 뜬다 — 봉인 재건(다시 가둔다) / 소멸(파편을 없앤다) / 수거(군에 넘긴다) / 은폐(덮고 물러난다) / 폭주 — 최종 균열·침식 수치와 선택에 따라 갈린다.
